The trades

The Strategy Lab builds its own strategies - which whales (call/put, days to expiry, time of day, size, bought or sold, IV, trend, the AI's opinions...) × how to get in × how to get out - and tests hundreds of millions of them on real IBKR prices, nonstop, using your PC's spare power. Trying that many always finds some that look amazing in hindsight, so the Lab only trusts two things: a blind test and a luck test.

Luck test: real result vs. shuffled data

Each grey bar = how the whole search did when the outcomes were shuffled (no real pattern left). The green line = the real blind result. It's only real if it beats almost all of the grey.
